# cc-class-site

## Project Overview
Marketing landing page for **Monday Morning Playbook** — a customer success tool that gives CS teams a weekly briefing with account health signals, prioritized actions, and team updates.

## Goals
- Drive free trial signups and demo requests from VP/Director-level CS buyers at mid-market B2B SaaS companies
- Communicate the value prop quickly: eliminate the Monday morning data assembly ritual
- Build credibility with social proof, an interactive ROI calculator, and transparent pricing
- Position against bloated CS platforms (Gainsight, Totango) by emphasizing fast time-to-value

## Tech Stack
- Plain HTML, CSS, and vanilla JavaScript — no frameworks or build tools
- Single-page static site (`index.html`)
- All styles inline in a `<style>` block
- All scripts inline in a `<script>` block
- No external dependencies

## Writing Copy
- Always reference `persona.md` when writing or editing copy — it defines the target buyer (Alex Rivera, VP of CS) and their pain points, goals, and buying criteria
- Keep language concise and benefit-driven; avoid jargon
- Use the buyer's own words where possible (e.g., "what's on fire, what's growing, what to do first")

## Key Files
- `index.html` — the landing page
- `persona.md` — buyer persona (target audience)
- `prd.md` — PRD for the landing page structure
- `prd-roi-calculator.md` — PRD for the ROI calculator section
